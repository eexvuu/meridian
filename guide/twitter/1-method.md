7/13

===

These are data that I look at.

1. Top holder % - does not matter if it is Raydium or a wallet. The number is what I want to see. Logically for a new coin, you dont expect to see under 5% even for Raydium, that is a red flag as it usually means a lot of people bought very early and are waiting to dump. And of course top holder higher than Raydium % is also a red flag for new coins.

2. Number of Holders - For a new coin, usually we will see 500-3000 holders, any number below or above warrants a red flag and should be avoided or look at other data first before DLMM.

3. MC/holder - the higher the number the more risky the coin is as the top holders might take profits and dump the chart. 

4. Insiders % - Anything more than 5% is a red flag.
5. Phishing % - More than 30% is a red flag
6. Bundler % - More than 30% is a red flag
7. Bluechip % - Less than 0.5% is a red flag for me as there is usually some problems with the holder wallets that Bluechip holders does not want to hold.

8. Number of Fresh wallets - Less than 100 is a warning, number tend to increase over time.
9. Number of Bundled wallets - Less than 100 is a warning, number tend to increase over time.
10. Number of Fresh wallets(8) divide by holders(2) - Above 40% is a red flag.
11. Number of Bundled wallets(9) divide by holders(2) - Above 40% is a red flag.
12. Type of red flag from rugcheck if there is any.

Then again just because the coin has red flags does not mean we cannot earn using DLMM. It just means to be careful with the strategy we should use. Usually if I have to DLMM a coin with some red flags I would go with a bigger pool than normal.
